# Skladka

Skladka - 3D-студия для изучения складок и создания референсов одежды. Здесь можно посмотреть, как ткань ложится на тело и предметы, меняется при движении и под ветром.

- Разные ткани, настройка размера и точек крепления.
- Манекен с изменяемой позой, туника, рукава, брюки, юбка и плащ.
- Композиции из тканей, манекенов, кубов и шаров.
- Настройка света и ветра, обычная и утрированная драпировка.
- 2D-контур и сохранение изображения.
