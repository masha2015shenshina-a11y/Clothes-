# Складка

Интерактивная 3D-студия ткани на React и Three.js. Работает в браузере без входа в ChatGPT.

## Разработка

Node.js 22: `npm ci`, `npm run check`, `npm run build`. Готовый сайт находится в `dist`.

## Публикация

В Settings → Pages выберите Source: GitHub Actions. Workflow Publish Skladka публикует main после проверки TypeScript и сборки. Его также можно запустить вручную через Actions → Publish Skladka → Run workflow.
