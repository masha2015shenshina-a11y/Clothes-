Skladka - небольшая 3D-студия для художников и дизайнеров. Создана, чтобы разбирать форму складок и собирать референсы: на манекене, на предметах или в собственной композиции.

### Что внутри

| | Возможности |
| :--- | :--- |
| **Ткань** | Разные материалы, размер полотна и редактируемые крепления. |
| **Одежда** | Туника, рукава, юбка, брюки и плащ. Настройка длины и посадки. |
| **Манекен** | Изменение позы и управление отдельными частями тела. |
| **Композиция** | Несколько тканей, манекены, кубы и шары. Перемещение, вращение и размеры объектов. |
| **Свет и движение** | Настраиваемое освещение, ветер и пауза симуляции. |
| **Референс** | Обычная и утрированная драпировка, 2D-контур и сохранение изображения. |

Интерфейс на русском и английском.

### Основа

TypeScript · React · Three.js · Vite
